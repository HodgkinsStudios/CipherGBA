# CipherGBA v0.1 — Initial cross-platform release

**HodgkinsStudios · GitHub tag `v0.1.0`**

CipherGBA v0.1 is the initial release of the C++17 Game Boy Advance emulator, with a native Linux X11 frontend and a portable SDL2 frontend targeting Windows x64, macOS Intel/Apple Silicon and Linux. The Linux AppImage and Flatpak package recipes are included.

## What's included

- Standalone core (shared library, optional static library) with integrated HLE BIOS and support for user-supplied original 16 KiB BIOS.
- `.gba` and supported `.zip` cartridge loading; GBA display and audio; keyboard/controller input; windowed/fullscreen operation.
- SRAM/Flash/EEPROM persistent saves, disk save-states, screenshots, TAS playback/recording, AVI capture, and supported GBA cheat formats.
- A unified application image for window icons, platform packaging and About windows.
- CI source/package assembly for Windows x64, macOS arm64/x86_64, Linux X11, AppImage and Flatpak, with checksums.

The SDL2 and X11 frontends differ in layout and feature availability. The GitHub Actions matrix is not a substitute for interactive testing on each OS.

## Accuracy results and limitations

The recorded suite baseline is **6,994/6,998 scored cases in each BIOS mode (99.9428%)**. Four HBlank timing assertions remain disputed and unresolved. The root cause has not been proven to be a problem with either the emulator or the test ROM. No 100% hardware-accuracy, all-games-compatibility, or universal full-speed guarantee is made. See [Accuracy](docs/ACCURACY.md), [Local verification](docs/VALIDATION.md), [Platform validation](docs/PLATFORM_ACCEPTANCE.md), and [Performance](docs/PERFORMANCE.md).

Windows/macOS interactive UI, audio and controller coverage, Flatpak portal behavior across desktop environments, and macOS notarization remain open acceptance items. Platform packages are generated by CI after the repository is uploaded and its checks succeed; their presence is **not** implied by this source-only archive.
